THE CANONICAL GRADIENT — VERBATIM FROM SOLANA.COM CSS
linear-gradient(135deg, #9945FF 10%, #14F195 90%)
Appears in exactly three places: the single decisive CTA of a view (Apply / Allow / Connect), the build-and-deploy progress indicator, and nowhere else as decoration. Everything else is flat purple or green — wallpapered gradients stop meaning anything.
TYPE — TWO TRACKS
Space Grotesk
Chrome, titles, buttons, Home, content. Solana's own faces (Diatype, ABC Mono) are proprietary — Space Grotesk ships in solana.com's own font stacks, so the substitute has brand provenance, not just resemblance.
JetBrains Mono
Editor, terminal, explorer tree, the assistant conversation. The IDE's monospace identity — kept.
SHAPE & BORDERS
12px default
panels, inputs, menus
16px cards
Home, proposals
9999px pills — buttons
Borders are lavender-white at low alpha (#ECE4FD1F / #ECE4FD33) — solana.com's own trick; it is what keeps the dark UI warm instead of gray.
