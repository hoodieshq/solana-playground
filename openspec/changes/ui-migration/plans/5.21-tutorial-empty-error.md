# 5.21 The tutorial page, its empty and error states (HOO-2072)

> Executed inline (`superpowers:executing-plans`). Steps use checkboxes.

**Goal:** the tutorial's about page, the sync banner and the not-found page
render from design-system parts, with no styled-components import left in
`components/Tutorial/views/About.tsx`, `components/Tutorial/TutorialDetails.tsx`,
`features/persistence/Component/SyncBanner.tsx` and
`views/main/primary/NotFound/NotFound.tsx`.

**Decided (Slava, 2026-10-21):** the start button keeps its labels `START`,
`CONTINUE`, `COMPLETED`; eight e2e specs find it by that exact name. Only its
look changes.

**Out of this task:** the stages' empty states are already on `StageEmpty`
(Build and Deploy, 5.11); Interact is 5.12. `Card` is not a registry item, so
the details box is token-styled markup, not an installed component; `Alert`
has no warning variant, so the banner uses `Callout variant="warning"`, which
carries `role="alert"`.
