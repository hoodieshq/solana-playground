# 1.1 Interact in two columns

Ticket: HOO-2491. Base: `scope/users-work`.

**Success metric (from the ticket):** on the preview, Interact for a program
with many instructions shows Call history beside the form without scrolling
past the form.

## Gaps (decided, sent to Design alignment, accepted 4 Nov)

- Container query on the stage; threshold set from the measured stage width at
  1512 px with chat and Files open, with a form floor of about 26rem (Design
  alignment's check). Measured value goes in the PR body.
- History column 18rem, sticky; form fluid up to 42rem; gap 1.5rem.
- Empty history in the wide layout: heading + "Calls you send show up here."
- Accounts and Events full width below; narrow keeps today's single column.

## Steps

1. Measure the stage width at 1512 x 900 with chat and Files open (Playwright,
   dev server on slot 8, port 13080). Pick the threshold.
2. Test first (`InteractBody.test.tsx`, `BaseCallHistory.test.tsx`):
   - before the first call, the Call history region shows the empty line;
   - the form and Call history share the columns container; Accounts sit
     outside it;
   - `BaseCallHistory` without `showEmpty` and no records renders nothing.
3. Implement: `@container` on the body, grid with the history column,
   `showEmpty` on `BaseCallHistory`, empty line hidden below the threshold.
4. Verify: `yarn run check`, screenshots before/after at 1512 and narrow,
   a state with a long instruction at the threshold.
